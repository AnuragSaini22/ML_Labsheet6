PROJECT 2: HOUSE PRICE PREDICTION SYSTEM

Purpose:
Predict house prices using area, bedrooms, location, bathrooms, parking and property age.

Algorithms compared:
- Linear Regression
- Random Forest Regression

Evaluation metrics:
- MAE
- RMSE
- R2 Score

Files:
- house_price_prediction.py : main ML program
- house_prices.csv          : sample dataset
- requirements.txt          : required Python libraries

Run:
1. pip install -r requirements.txt
2. python house_price_prediction.py

The program compares both regression algorithms and saves the Random Forest model as house_price_model.joblib.
