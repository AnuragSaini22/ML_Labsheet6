PROJECT 1: STUDENT PERFORMANCE PREDICTION SYSTEM

Purpose:
Predict a student's final academic score using attendance, internal marks, assignments, study hours, and previous semester result.

Files:
- student_performance_prediction.py : main ML program
- student_performance.csv            : sample dataset
- requirements.txt                   : required Python libraries

Run:
1. pip install -r requirements.txt
2. python student_performance_prediction.py

The program evaluates the model using MAE, RMSE and R2 Score, predicts a new student's score, and saves the trained model.
